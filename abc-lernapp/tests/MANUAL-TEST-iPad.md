# Manueller Test auf dem iPad – ABC mit Bruno

Die automatischen Tests laufen in Chromium. Safari auf dem echten iPad verhält sich bei Ton, Touch,
Apple Pencil und Home-Bildschirm anders. Diese Liste deckt genau das ab. Dauer: ca. 20 Minuten
(ohne Kind), danach die Beobachtung mit dem Kind.

Gerät: ______________  iPadOS: ______  Datum: ________  App-Version/Link: ______________

## 1. Vorbereitung

- [ ] iPad aktualisiert, Lautstärke auf ca. 50 %, **Stummschalter/Kontrollzentrum: Ton an**.
- [ ] Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → **Deutsch**: eine gute
      Stimme (z. B. „Anna (Erweitert)“) herunterladen.
- [ ] Bildschirmzeit/Auto-Sperre: für den Test auf „Nie“ oder 15 Minuten.

## 2. In Safari öffnen

- [ ] Link in Safari öffnen. Die Seite lädt in unter 2 Sekunden, ohne weißen Blitz.
- [ ] Querformat: alles passt auf den Bildschirm, nichts ist abgeschnitten, kein seitliches Wischen möglich.
- [ ] Die Schrift ist rund (Fredoka), nicht die Standardschrift.
- [ ] **Ton nach dem ersten Antippen:** Auf Bruno tippen → Bruno spricht auf Deutsch.
      (Vor dem ersten Tippen darf nichts zu hören sein – Safari blockiert das.)
- [ ] Ein Buchstabe im ABC → „A. A wie Affe.“ ist deutlich und nicht zu schnell.
- [ ] Doppeltippen zoomt **nicht**, Zwei-Finger-Zoom zoomt nicht, langes Drücken zeigt **kein**
      Kopieren/Lupe-Menü.
- [ ] Nach unten ziehen lädt die Seite **nicht** neu.

## 3. Zum Home-Bildschirm

- [ ] Teilen → **Zum Home-Bildschirm** → Name „ABC Bruno“. Das Symbol sieht ordentlich aus.
- [ ] Vom Home-Bildschirm starten: **Vollbild ohne Adressleiste**, Statusleiste stört nicht.
- [ ] Oben (Uhr/Kamera) und unten (Home-Balken) überdeckt nichts die Bedienelemente.
- [ ] App schließen (wegwischen) und neu öffnen: Name, Sterne und Einstellungen sind noch da.
- [ ] **Flugmodus an**, App öffnen: Startet sie? Funktionieren alle Bereiche? (Notieren, falls nicht –
      Offline-Betrieb ist für Phase 3 geplant.)

## 4. Drehen

- [ ] Hochformat ↔ Querformat in jedem Bereich (Start, ABC, Finden, Malen, Elternbereich, Feier).
      Nichts springt, nichts wird abgeschnitten.
- [ ] Beim Nachmalen drehen: Vorlage passt sich an (ein angefangenes Bild darf verschwinden).
- [ ] Geteilter Bildschirm / Slide Over (falls genutzt): bleibt bedienbar.

## 5. Bereiche durchspielen

**ABC**
- [ ] 26 Buchstaben sichtbar, Antippen öffnet die große Karte, ◀ ▶ blättern, ✕ schließt.
- [ ] Tippen neben die Karte schließt sie auch.

**Finden**
- [ ] Bruno fragt „Wo ist das …?“. Sprechblase antippen wiederholt die Frage.
- [ ] Falscher Ballon: Ballon wackelt, Bruno sagt freundlich, welcher Buchstabe das ist. Kein Fehlerton.
- [ ] 5 richtige → Konfetti + Feier, „Nochmal spielen“ und „Zum Start“ funktionieren.
- [ ] Während Bruno lobt schnell auf einen anderen Tab tippen: Die Feier darf **nicht** plötzlich
      woanders erscheinen.
- [ ] Mehrmals schnell auf den richtigen Ballon tippen: nur 1 Stern.

**Nachmalen**
- [ ] Mit dem **Finger** malen: Linie folgt ohne Verzögerung, die Seite scrollt dabei nicht.
- [ ] Mit dem **Apple Pencil**: genauso flüssig, Druck/Neigung stören nicht, Handballen auf dem
      Display malt nicht versehentlich mit (notieren).
- [ ] Buchstaben nachfahren → Fortschrittsbalken wächst, ab ca. ⅔ gibt es Stern + Konfetti + Lob.
- [ ] Wild über die ganze Fläche kritzeln: Gibt es auch dann einen Stern? (notieren – ggf. zu leicht)
- [ ] Schwamm löscht, ◀ ▶ wechseln den Buchstaben, Farben wechseln.

**Elternbereich**
- [ ] Schloss **kurz** antippen: nichts passiert.
- [ ] Schloss **2 Sekunden halten**: Balken läuft voll, Elternbereich öffnet sich.
- [ ] Während des Haltens den Finger wegziehen: bricht ab.
- [ ] Name ändern → Begrüßung zeigt sofort den neuen Namen; nach Neustart noch da.
- [ ] Schreibweise „a b c“ → ABC und Finden zeigen Kleinbuchstaben. Ton „Aus“ → Stille.
- [ ] „Zurücksetzen“: erster Tipp fragt „Wirklich löschen?“, erst der zweite löscht die Sterne.
- [ ] Die Tastatur verdeckt das Namensfeld nicht.

## 6. Geführter Zugriff (Kindersicherung)

- [ ] Einstellungen → Bedienungshilfen → **Geführter Zugriff** an, Code festlegen.
- [ ] App starten, **3× Seitentaste** (bzw. Home-Taste) → Geführter Zugriff starten.
- [ ] Optional: Bereiche einkreisen, die deaktiviert sein sollen (z. B. Schloss-Knopf).
- [ ] Wischen vom Rand, Home-Geste, Kontrollzentrum: Kind kommt **nicht** aus der App.
- [ ] Zeitlimit testen (z. B. 15 Minuten) – was passiert, wenn es abläuft?
- [ ] Beenden: 3× Seitentaste + Code.

## 8. Fehler melden

Für jeden Fehler: Bildschirmfoto (Seitentaste + Lauter), Gerät/Ausrichtung, was getan wurde, was
erwartet war, was passiert ist.
